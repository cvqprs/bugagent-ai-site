Schnellstart-Anleitung

Einrichtungs- & Verbindungsanleitungen

Verbinde BugAgent AI in unter 2 Minuten mit deinem Jira-Workspace und deinen bevorzugten KI-Engines.

Verbindung mit Jira Cloud & Server/Data Center

  1. Öffne das Seitenpanel und gehe zu Einstellungen (Settings) → Jira Connection.
  2. Gib die URL deiner Jira-Instanz ein (z. B. https://deine-firma.atlassian.net oder eigene Domain).
  3. Für Jira Cloud: Gib deine Atlassian-E-Mail und ein API-Token von id.atlassian.com ein.
    Für Server/Data Center: Wähle Personal Access Token (PAT) und füge dein Token ein.
  4. Klicke auf Test Jira Connection. Nach erfolgreicher Prüfung klicke auf Save Settings.

So erhältst du deinen Google Gemini API-Key

  1. Besuche Google AI Studio (aistudio.google.com) und melde dich mit deinem Google-Konto an.
  2. Klicke auf Create API key, wähle dein Google-Cloud-Projekt und kopiere den Schlüssel.
  3. Füge den Schlüssel in den Einstellungen in das Feld Gemini Vision Key ein und klicke auf Save Settings.

So erhältst du deinen OpenAI API-Key (GPT-4o & GPT-4o-mini)

  1. Öffne die OpenAI Developer Platform (platform.openai.com) und melde dich an.
  2. Klicke auf Create new secret key, vergib einen Namen (z. B. BugAgent AI) und klicke auf Create secret key.
  3. Kopiere deinen Schlüssel (beginnt mit sk-...), füge ihn unter OpenAI Vision Key ein und klicke auf Save Settings.

So erhältst du deinen Anthropic Claude API-Schlüssel (Sonnet & Haiku)

  1. Öffne die Anthropic Console (console.anthropic.com) und melde dich an.
  2. Klicke auf Create Key, vergib einen Namen (z. B. BugAgent AI) und klicke auf Add.
  3. Kopiere deinen Schlüssel (beginnt mit sk-ant-...), füge ihn in den Einstellungen unter Claude API-Schlüssel ein, wähle Sonnet oder Haiku und klicke auf Save Settings.

Verwendung von Localhost-KI (Ollama - 100% Offline & Kostenlos)

  1. Installiere Ollama von ollama.com und lade ein Vision-fähiges Modell herunter (z. B. ollama run moondream oder ollama run llama3.2-vision).
  2. Starte den Ollama-Server mit CORS-Freigabe für Browsererweiterungen: unter macOS/Linux mit OLLAMA_ORIGINS="*" ollama serve (oder Umgebungsvariable unter Windows).
  3. Wähle in den BugAgent AI-Einstellungen Localhost AI (Ollama), klicke auf Fetch Models, wähle dein Vision-Modell und speichere.
