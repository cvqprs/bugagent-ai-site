Guía de Inicio Rápido

Instrucciones de configuración y conexión

Sigue estas sencillas guías para conectar BugAgent AI con tu espacio de Jira y modelos de IA en menos de 2 minutos.

Cómo conectar Jira Cloud y Server/Data Center

  1. Abre el panel lateral de la extensión y ve a Ajustes (Settings) → Jira Connection.
  2. Introduce la URL de tu instancia de Jira (ej. https://tu-empresa.atlassian.net o tu dominio propio).
  3. Para Jira Cloud: Introduce tu email de Atlassian y un API Token creado en id.atlassian.com.
    Para Server/Data Center: Selecciona Personal Access Token (PAT) y pega tu token.
  4. Haz clic en Test Jira Connection. Tras verificar, haz clic en Save Settings.

Cómo obtener tu clave de Google Gemini API

  1. Visita Google AI Studio (aistudio.google.com) e inicia sesión con tu cuenta de Google.
  2. Haz clic en Create API key, selecciona tu proyecto de Google Cloud y copia la clave generada.
  3. Pega la clave en Ajustes en el campo Gemini Vision Key y pulsa Save Settings.

Cómo obtener tu clave de OpenAI API (GPT-4o y GPT-4o-mini)

  1. Accede a la plataforma OpenAI Developer Platform (platform.openai.com) e inicia sesión.
  2. Haz clic en Create new secret key, asígnale un nombre (ej. BugAgent AI) y pulsa Create secret key.
  3. Copia tu clave (empieza con sk-...), pégala en Ajustes → OpenAI Vision Key y pulsa Save Settings.

Cómo obtener tu clave API de Anthropic Claude (Sonnet y Haiku)

  1. Visita la plataforma Anthropic Console (console.anthropic.com) e inicia sesión en tu cuenta.
  2. Haz clic en Create Key, asígnale un nombre (p. ej. BugAgent AI) y pulsa Add.
  3. Copia tu clave (empieza con sk-ant-...), pégala en Ajustes → Clave API de Claude, elige Sonnet o Haiku y pulsa Save Settings.

Cómo usar IA Localhost (Ollama - 100% Offline y Gratis)

  1. Instala Ollama desde ollama.com y descarga un modelo de visión (p. ej. ollama run moondream o ollama run llama3.2-vision).
  2. Inicia el servidor Ollama permitiendo CORS: en macOS/Linux con OLLAMA_ORIGINS="*" ollama serve (o configura la variable de entorno en Windows).
  3. En Configuración de BugAgent AI, selecciona Localhost AI (Ollama), haz clic en Fetch Models, selecciona tu modelo de visión y guarda.
