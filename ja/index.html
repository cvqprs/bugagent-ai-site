主な機能と特徴

現代のQAチームとソフトウェアテスターのために構築

UIのリグレッションやソフトウェアの不具合をシームレスにキャプチャ、解析、注釈付け、報告するために必要なすべてが揃っています。

ワンクリック、ドラッグ＆ドロップとショートカット

ワンクリックで表示中のタブを即座にキャプチャ、スクリーンショットを直接ドラッグ＆ドロップ、またはグローバルショートカット：⌘+Shift+S（macOS）および Alt+Shift+S（Win/Linux）を利用可能。

4エンジン Vision AI ハブ（Claude, Gemini, OpenAI & Ollama）

Anthropic Claude（Sonnet & Haiku）、Google Gemini（3.8 Flash）、OpenAI（GPT-4o）、OllamaローカルAI（100%オフライン）を自在に切り替え。根本原因の仮説や再現手順を6言語で自動生成します。

Jira向け動作環境スペックの自動検出

OS、ブラウザのバージョン、ビューポート解像度、Retinaスケーリング比率を自動抽出し、手入力不要で美しいJira Wiki形式のテーブルとして整形します。

完全なダークモードと洗練されたUI

長時間のQAテストセッションでも目に優しい設計。ヘッダーの専用トグルで、明るいライトモードとバッテリー消費を抑えるダークモードをワンタッチで切り替えられます。

内蔵アノテーションとGDPR準拠ぼかし機能

Jiraに送信する前に、スクリーンショット上に矩形、矢印、テキスト注釈を描画したり、顧客の機密データ（個人情報、トークン、メールアドレス）を直接ぼかすことができます。

100%プライバシー（ローカルOllama & BYOK）

データに対する完全な制御。Ollamaを使用して端末内のみでビジョン解析を実行するか、Gemini・OpenAI・Anthropic Claudeに自身のAPIキーを使用（BYOK）。すべての認証情報はブラウザ内のローカルストレージに保持され、追跡は一切行われません。

設定および接続手順

わずか2分でBugAgent AIをJiraワークスペースおよび各種AIエンジンに接続できます。

Jira Cloud および Server/Data Center の接続方法

  1. 拡張機能のサイドパネルを開き、Settings → Jira Connection に移動します。
  2. JiraインスタンスのURLを入力します（例: https://your-company.atlassian.net または独自ドメイン）。
  3. Jira Cloudの場合: Atlassianアカウントのメールと id.atlassian.com で作成した APIトークン を入力。
    Server/Data Centerの場合: Personal Access Token (PAT) を選択してトークンを貼り付け。
  4. Test Jira Connection をクリック。接続が確認できたら Save Settings をクリックします。

Google Gemini APIキーの取得方法

  1. Google AI Studio (aistudio.google.com) にアクセスし、Googleアカウントでログインします。
  2. Create API key をクリックし、Google Cloudプロジェクトを選択して生成されたキーをコピーします。
  3. 設定画面の Gemini Vision Key に貼り付け、Save Settings をクリックします。

OpenAI APIキー (GPT-4o & GPT-4o-mini) の取得方法

  1. OpenAI Developer Platform (platform.openai.com) にアクセスしてログインします。
  2. Create new secret key をクリックし、キーの名前（例: BugAgent AI）を入力して作成します。
  3. キー（sk-... で始まる文字列）をコピーし、設定の OpenAI Vision Key に貼り付けて Save Settings をクリックします。

Anthropic Claude APIキー（Sonnet & Haiku）の取得方法

  1. Anthropic Console (console.anthropic.com) にアクセスしてログインします。
  2. Create Key をクリックし、キー名（例: BugAgent AI）を入力して Add をクリックします。
  3. キー（sk-ant-... で始まる文字列）を設定画面の Claude API キー に貼り付け、Sonnet または Haiku を選択して Save Settings をクリックします。

ローカルAI（Ollama - 完全オフライン・無料）の設定方法

  1. ollama.com からOllamaをインストールし、ビジョン対応モデル（例: ollama run moondream または ollama run llama3.2-vision）を取得します。
  2. ブラウザ拡張用のCORSを許可して起動します: macOS/Linuxでは OLLAMA_ORIGINS="*" ollama serve を実行（Windowsでは環境変数を設定）。
  3. BugAgent AIの設定で Localhost AI (Ollama) を選択し、Fetch Models をクリックしてビジョンモデルを選択し、保存します。

サポートが必要な場合や不具合を見つけた場合

開発チームはサポートや問題報告を継続的に確認しています。動作不良や機能の要望がある場合は、GitHubリポジトリでIssueを作成してください。
